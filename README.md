# minishell

Interpréteur de commandes en C (Linux) — projet de programmation système, M1 IBD, Université Paris 8, automne 2024.
Réalisé en binôme : MADANI, SAIDI.

Lancement : `make`, puis `./src/minishell`.

Sources : `src/main.c` (boucle), `src/parser.c` (analyse de la ligne),
`src/cmd.c` (exécution, redirections, tubes), `src/builtin.c` (commandes internes).

L'historique reconstitue les trois rendus conservés : 31 octobre, 20 novembre et 13 décembre 2024.
